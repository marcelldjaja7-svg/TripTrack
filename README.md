# Triply

Track. Relive. Share. — a Strava-style trip app with story-ready share designs.

## Features

- **Onboarding** — full-bleed hero with Get Started
- **Live Record** — dark map tracking with distance, speed, elevation, pause/finish
- **Trip Summary** — metrics grid + elevation profile
- **Share Designs** — Story / Photo / Minimal / Map / Stats templates, export image
- **Social Feed** — For You / Following / Nearby posts
- **Explore** — discover map + featured routes
- **Trips & Profile** — photo grids, stats, share entry points

Trips persist locally (AsyncStorage). Web uses a demo GPS path; native uses device GPS.

## Run

```bash
npm install
npx expo start
```
